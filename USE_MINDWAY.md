# How to Use Mindway

## For any AI

Add this instruction:

```text
Read https://github.com/contactwichit-design/mindway/blob/main/my.md before all work. Then use /my.
```

Then begin a task with:

```text
/my
```

## What `/my` should do

1. Read the public Mindway entry.
2. Understand the current task and available sources.
3. Separate facts, assumptions, risks, and missing information.
4. Protect sensitive information.
5. Select the smallest useful set of skills and tools.
6. Complete the work or stop clearly at a genuine blocker.
7. Summarize the result, unresolved points, and next action.
8. Preserve only useful learning; avoid duplicate logs and files.

## What Mindway does not provide

Public Mindway does not provide access to zaft's private files, company information, accounts, memory, credentials, projects, or private extensions.

Each person or organization connects its own authorized sources and remains responsible for its own data, decisions, policies, and permissions.

## Useful cases

Mindway may help with:

- starting work with clearer context;
- continuing work across different AI systems;
- organizing sources and decisions;
- reducing duplicate work;
- handling problems without losing the main task;
- turning lessons into reusable skills;
- sharing safe knowledge with others.

Mindway is not medical, legal, financial, security, or professional advice.
